# Gravitational radiation from a photon on the light ring: companion repository

Codes, stored results and the companion notebook of the paper

> E. Barausse, *Gravitational radiation from a photon on the light ring: multipole fluxes and the
> logarithmic divergence*, submitted to Phys. Rev. D.

The paper derives analytically the 1/ℓ law of the multipole fluxes emitted by a massless particle on
the circular null geodesic of a Schwarzschild or Kerr black hole (hence the logarithmic divergence of
the total flux), with the coefficient κ = 0.063653 and the spin factor g(a) in closed form, and checks
every result against numerical solutions of the Zerilli–Regge–Wheeler equations (ℓ ≤ 12800) and of the
Teukolsky equation (ℓ ≤ 800). This repository contains everything needed to reproduce the analytic
results, the numbers, the table and the figures of the paper.

## Layout

| path | content |
|---|---|
| `notebook/PhotonLightRing.nb` (`.wl`) | companion Mathematica notebook, which reproduces the calculations of the paper section by section (generated by `notebook/make_notebook.py`) |
| `notebook/kerr_mathematica_runL1.m`, `runL2.m` | output of the notebook's own Kerr Teukolsky integrator (ℓ = 100 … 800, a = 0, 1/2, 9/10), a cross-check of `kerr_py/` |
| `schwarzschild/` | Mathematica code for the Schwarzschild light ring (Secs. II, III and VI A) |
| `photon_big_results.m` | output of `schwarzschild/run_big.wls`: the photon fluxes for ℓ = 10 … 12800, j = ℓ − m = 0 … 4 (Sec. III D, Fig. 1) |
| `timelike_results.m` | output of `schwarzschild/run_timelike.wls`: fluxes from massive particles near the light ring, γ = 5, 10, 20 (Sec. VI A) |
| `kerr_py/` | Python Teukolsky solver for the photon on the Kerr light ring and its stored run `kerr_results.json` (Sec. IV, Table I, Fig. 2) |
| `kerr_analytic/` | the analytic Kerr coefficients κ_j(a), g(a) and the stored tables `kerr_kappa_analytic.json`, `kerr_g_finegrid.json`, `kerr_g_curve.json` (Sec. IV, Table I) |
| `figures/` | `make_fig1.py`, `make_fig2.py`: the two figures of the paper from the stored data |
| `toolkit_checks/` | the cross-checks against the Black Hole Perturbation Toolkit at ℓ ≤ 5 quoted in Secs. II, III D and IV |
| `sympy_check/` | an independent Python (sympy/mpmath/scipy) reproduction of every analytic formula and quoted number of the paper, with its saved report |

File-level documentation is in the header of every script (purpose, conventions, inputs and outputs,
how to run, cost, section of the paper).

## Conventions

* Geometrical units G = c = 1 and M = 1 in all codes. Fluxes are per E² (E the Killing energy of the
  photon), i.e. the quantity Ė M²/E² of the paper.
* Every run stores a single m > 0 per mode, labelled by j = ℓ − m (the five or four dominant m). The −m
  mode gives the same flux, so the physical flux per ℓ is twice the sum over j; this is how
  κ = 2 Σ_j κ_j and all comparisons with the paper are built.
* The sources, the homogeneous solutions, the Wronskian normalisation and the flux formulae follow the
  `ReggeWheeler` and `Teukolsky` packages of the Black Hole Perturbation Toolkit (the photon source is
  the Toolkit circular-orbit source with E → E, L → bE, Υ_t → r0² p^t).
* Kerr: negative spin denotes a retrograde orbit (a → −a with m > 0). The light ring is parametrised
  either by a or by its radius r0.
* Timelike orbits: r0 = 3M(1 + δ), γ = E/μ, with the δ of the paper (one third of the δ of Breuer et
  al. 1973).

## Environment

* Mathematica 15.0.1 with the Black Hole Perturbation Toolkit paclets installed from
  `https://pacletserver.bhptoolkit.org` (`ReggeWheeler` 0.3.0, `Teukolsky` 1.2.1,
  `SpinWeightedSpheroidalHarmonics`, `KerrGeodesics`). The Toolkit is used only in `toolkit_checks/`
  and in the five Toolkit cells of the notebook (commented out); the production integrators are
  self-contained (they only load the `ReggeWheeler` package). `wolframscript` must be able to find the
  kernel (e.g. `export WOLFRAMSCRIPT_KERNELPATH=/Applications/Wolfram.app/Contents/MacOS/WolframKernel`);
  `WolframKernel -noprompt < script.wls` works as well.
* Python 3.14 with `numpy` 2.5.3, `scipy` 1.18.1, `sympy` 1.14.0, `mpmath` 1.3.0 and `matplotlib`
  3.11.2 (the versions used for the paper; any recent versions should do). For example, from the
  repository root,

      python3 -m venv venv && venv/bin/pip install numpy scipy sympy mpmath matplotlib

  The `venv/` directory is not tracked; the commands below assume `python` is that interpreter.

## Reproducing the results of the paper

Each item gives the statement of the paper, the script that produces it, the command and the rough
cost on a laptop. Section and equation numbers refer to the submitted version.

**Sec. II, Toolkit cross-check of the null source** (Zerilli–Regge–Wheeler and Teukolsky fluxes agree
to the precision of the Toolkit's solutions, nine to twenty digits, at ℓ ≤ 5); run from `toolkit_checks/`:

    wolframscript -file schwarzschild_toolkit.wls    # l = 2, 3, 5: Toolkit MST, Teukolsky, and the two integrators of schwarzschild/, a few minutes

The same comparison at ℓ = 5 is in the Toolkit cell of Section III D of the notebook (commented out).

**Secs. III A–III C, analytic results** (jumps, Eq. (5); barrier expansion, Eq. (7); κ_j, Eqs. (11)–(13);
cross term 1.0390, cubic term −0.231, σ_0 = 0.81, σ̄ = 0.61; horizon fraction 40 %): the notebook,
Sections III A–III C, and `sympy_check/reproduce_paper.py` (Secs. III A–III C).

**Sec. III D and Fig. 1, Schwarzschild numerics**; run from `schwarzschild/`:

    wolframscript -file run_big.wls          # -> ../photon_big_results.m, about an hour (a minute per mode at l = 12800)
    wolframscript -file run_big.wls 10 20    # quick test: l = 10, 20 only, written to photon_big_test.m in the current directory
    wolframscript -file asym_check.wls       # the cross term 1.0389 and the barrier asymmetry -0.231 at l = 6400, a few minutes

The three-term fit (Σ_j κ_j = 0.0318263), the κ_j at ℓ = 12800 and the m-summed asymmetry are evaluated
from `photon_big_results.m` in Section III D of the notebook and in `sympy_check/`. The validation of
the integrator against the Toolkit at ℓ ≤ 5 is the `MP` line of `toolkit_checks/schwarzschild_toolkit.wls`
above (relative agreement 10⁻⁸–3 × 10⁻⁷ at ℓ = 5, 10⁻⁷–10⁻⁵ at ℓ = 2, 3, where the WKB boundary data at
r* = ±40M are least accurate; the arbitrary-precision integrator `NI` shows the same differences, so they
are not round-off). Figure 1: from `figures/`,

    python make_fig1.py                      # fig1.pdf from ../photon_big_results.m, seconds

**Sec. IV and Table I, analytic Kerr coefficients**; run from `kerr_analytic/`:

    python run_kerr.py                       # -> kerr_kappa_analytic.json (seven spins of Table I, j <= 3), about a minute
    python run_kerr.py --grids               # also kerr_g_finegrid.json (g at a = 0.98, 0.995, ...) and kerr_g_curve.json
    python run_kerr.py --spins 0.5           # one spin, printed only
    python alpha_expand.py                   # Schwarzschild check: the kappa_j of Sec. III C from the Teukolsky side

The closed forms of Sec. IV (Eq. (15), N = 16M²/r0⁶, e^{2J_H}, Â_0, B̂, Eq. (21), the horizon/infinity
ratio) are derived symbolically in Section IV of the notebook and in `sympy_check/`; Table I is
evaluated in the notebook from the same ingredients.

**Sec. IV, Table I (last column) and Fig. 2, Kerr numerics**; run from `kerr_py/`:

    python validate_kerr.py                  # against the Toolkit (toolkit_reference.txt) at l <= 5, about ten seconds
    python run_production.py                 # -> kerr_results.json (a = 0, +-0.5, +-0.9; l = 10 ... 800; j <= 3), about ten minutes
    python run_production.py --cases 0.5 --ls 10 --jmax 0 --out test.json     # a single mode, a few seconds
    python summarize.py                      # table of the stored results, with the asymmetries sqrt(l)(I-H)/(I+H)

The Richardson extrapolation (agreement with 2g(a)Σ_{j≤3}κ_j to better than 1.5 × 10⁻⁵) and the
asymmetries at ℓ = 800 (0.78, 1.10, 0.51, 0.45) are evaluated from `kerr_results.json` in the notebook
and in `sympy_check/`. The Toolkit reference values of `toolkit_reference.txt` are produced by
`toolkit_checks/kerr_toolkit.wls` (`wolframscript -file kerr_toolkit.wls`, about ten minutes); the
notebook's own Toolkit-based Kerr integrator (Section IV) wrote `notebook/kerr_mathematica_runL1.m`
and `runL2.m`, which agree with `kerr_results.json`. Figure 2: from `figures/`,

    python make_fig2.py                      # fig2.pdf from ../kerr_py/kerr_results.json and ../kerr_analytic/kerr_kappa_analytic.json

**Sec. IV, comparison with Chrzanowski and Misner (1974)** (their constant 0.94 of ours; the m-counting
of the 1973–74 formulae checked against an exact scalar flux; the factors (s!)² = 4 and 1.065): Section V
of the notebook and `sympy_check/` (Sec. IV), which contains an independent scalar Regge–Wheeler
integrator.

**Sec. V, comparison with Breuer, Ruffini, Tiomno and Vishveshwara (1973)**: the null limits of their
Eqs. (14)–(15) (κ_0 and κ_1/4) are in Section V of the notebook and in `sympy_check/`; the exact
odd-mode ratios 3.15, 3.48, 3.64, 3.77 at δ = 10⁻⁴ and the fits 4.06 / 4.05 come from

    cd kerr_py && python check_odd_BRTV.py   # Teukolsky fluxes for timelike orbits, a few minutes

(their output is not stored; `sympy_check/` recomputes the same ratios with its own integrator).

**Sec. VI A, timelike orbits**; run from `schwarzschild/`:

    wolframscript -file run_timelike.wls     # -> ../timelike_results.m (gamma = 5, 10, 20; l up to 4800), about an hour

The comparison with Eq. (24) (better than 1 % for γ = 20, 0.4–4 % for γ = 10, better than 4 % for
γ = 5) is in Section VI A of the notebook and in `sympy_check/`.

**Sec. VII, energy per orbit and the M87\* estimate** (4.2 (E²/M) ln ℓ_max; ℓ_max ~ 10¹⁷, E/M ~ 10⁻⁷⁹,
ΔE/E ~ 10⁻⁷⁷): Section VII of the notebook and `sympy_check/`.

## The companion notebook

`notebook/PhotonLightRing.nb` (also as the plain-text package `PhotonLightRing.wl`) follows the paper
section by section: it derives the jumps, the barrier expansion, the parabolic-cylinder matching and the
κ_j; re-runs the Schwarzschild integrators at small ℓ and reads `photon_big_results.m` for the
large-ℓ numbers; derives all the Kerr closed forms symbolically and evaluates Table I; runs its own
Toolkit-based Kerr integrator at ℓ ≤ 800 (slow: about 40 s per mode) and compares with
`kerr_py/kerr_results.json`; and evaluates the comparisons with the 1973–74 formulae, the timelike
orbits and the estimates of the Conclusions. It reads the stored results by relative path (the
repository root is the parent of `notebook/`), so the repository layout should be kept. The five cells
that need the Toolkit are commented out and the rest does not depend on them. The notebook is generated
from `notebook/make_notebook.py` (`python make_notebook.py` rewrites both files).

## The SymPy check

`sympy_check/reproduce_paper.py` re-derives, independently of Mathematica and of the Toolkit, every
numbered equation and every number quoted in the text, the table, the captions and the footnotes of
the paper (symbolic identities with sympy, numerics with mpmath and scipy), reading the stored data
files but never regenerating them. `cd sympy_check && ../venv/bin/python reproduce_paper.py` takes
about four minutes and writes `report.txt`; the saved report and the list of checks are described in
`sympy_check/README.md`.
